03 / 你可能想知道

还有一点小问题？

更多问题，欢迎在 GitHub Issues ↗ 交流。

可以直接在这个网页开播吗？+

不可以。这是项目介绍与下载页面，不是在线控制台。扫码登录、直播间管理和获取推流凭据需要在下载的桌面程序中完成。

下载时应该选择哪个版本？+

Windows 选择 Windows-amd64；搭载 Intel 芯片的 Mac 选择 macOS-amd64，Apple Silicon（M 系列）选择 macOS-arm64。请以 Releases 中实际提供的文件为准；其他环境可参考源码启动说明。

拿到推流凭据就已经开始直播了吗？+

程序负责开启直播间并获取凭据，画面与声音还需要使用 OBS 等推流软件传输。请将地址与密钥分别填入推流软件的自定义服务器设置，并在软件中开始推流。

使用时有哪些需要注意的地方？+

请只从本项目 GitHub 下载程序，不要分享 Cookie、登录二维码或推流密钥。项目仅供个人学习、研究和非商业用途；使用前请确认符合平台规则及法律法规，并确保直播内容已获得合法授权。平台接口与规则可能变化，本工具不保证所有账号都能开播。
